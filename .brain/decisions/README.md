# Decisions Directory

ใช้เก็บบันทึกการตัดสินใจสำคัญในโปรเจกต์

## Format
ตั้งชื่อไฟล์ตามวันที่: `YYYY-MM-DD-topic.md`

## ตัวอย่างไฟล์
```markdown
# [หัวข้อ]

## บริบท
ทำไมต้องตัดสินใจเรื่องนี้

## ทางเลือก
1. ทางเลือก A
2. ทางเลือก B

## การตัดสินใจ
เลือกทางเลือก X เพราะ...

## ผลกระทบ
ไฟล์ที่แก้ / สิ่งที่เปลี่ยน
```
